# Study Planner

Study Planner là ứng dụng web hỗ trợ người dùng quản lý môn học, nhiệm vụ và lịch học cá nhân.

Dự án được thực hiện trong quá trình thực tập cá nhân nhằm thực hành phát triển ứng dụng Web Full-stack với Next.js.

## Công nghệ sử dụng

- Next.js
- React
- TypeScript
- Tailwind CSS
- Git
- GitHub

## Chức năng hiện tại

### Dashboard
- Hiển thị số môn học
- Hiển thị số nhiệm vụ
- Hiển thị số nhiệm vụ đã hoàn thành
- Hiển thị nhiệm vụ sắp tới

### Môn học
- Hiển thị tên môn học
- Hiển thị giảng viên
- Hiển thị phòng học

### Nhiệm vụ
- Hiển thị tên nhiệm vụ
- Hiển thị môn học
- Hiển thị deadline
- Hiển thị trạng thái
- Hiển thị mức độ ưu tiên

### Lịch học
- Hiển thị môn học
- Hiển thị ngày học
- Hiển thị thời gian
- Hiển thị phòng học
